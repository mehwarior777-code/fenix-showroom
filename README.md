# fenix-showroom

Шоурум-витрина на GitHub Pages: клиент **до заказа** видит, что получит.

- «Лицевая часть» будущего сайта и «админка» (Битрикс24) — переключаются ползунком-слайдером;
- карточки всех услуг с ценами;
- блок «Как заказать» (Telegram);
- заглушка ИИ-чата (подключается живой чат от локального ИИ).

## Файлы
- `index.html` — весь шоурум в одном файле (HTML+CSS+JS), без внешних зависимостей.

## Как поменять
- ссылка на Telegram — в конце `index.html`, переменная `TG` в блоке `// ===== ссылка на Telegram =====`;
- тексты «лицевой части» — в блоке `.site` (под конкретного клиента);
- услуги — карточки в блоке `#services`.

## Публикация
Репозиторий настроен на GitHub Pages: Settings → Pages → Source: main / root.
Ссылка: `https://mehwarior777-code.github.io/fenix-showroom/`
